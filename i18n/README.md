# Английская версия сайта

Начата 07.10.2026. Источник английского — русские страницы и перевод `i18n/en.tsv`.

## Как обновлять

1. Правите русскую страницу (`ru.html`, `ru-multi-*.html`).
2. `python build_en.py` — пересобирает `en.html` и `en-multi-*.html`.
   Если в русском тексте появилась новая фраза, скрипт остановится и покажет её:
   добавьте строку `русская фраза<TAB>перевод` в `i18n/en.tsv` и запустите снова.
3. Английские страницы руками не правим — перезапишутся.

Тот же `en.tsv` берёт дубайский сайт (`marketingdna-dubai/make_tr.py`), поверх него —
дубайские замены `marketingdna-dubai/i18n/en_dubai.tsv` (AED, Дубай вместо Латвии).
Фразу достаточно перевести один раз.

## Где живёт английский

| Место | Файл | Как сделано |
|---|---|---|
| 7 страниц сайта | `en.html`, `en-multi-*.html` | `build_en.py` из русских страниц |
| Кнопка EN в переключателе | все `ru*`, `index.html`, `lv-multi-*` | ссылка на английскую страницу |
| Условия, политика | `terms.html`, `privacy.html` | раздел EN уже был, ссылки `?lang=en` |
| Отказ от договора | `atteikums.html` | словарь `T.en`, `?lang=en` |
| Страница теста | `test.html` | словарь `T.en`, `?l=en` |
| Бот, Telegram | параметр `start=en_…` | английский флоу бота; ссылка клиента — `en_L_…` (до 59 символов) |
| Бот, WhatsApp | «(entry code: web-en-…)» | бот определяет язык по `web-en-` |
| Оплата | те же ссылки Stripe, `client_reference_id=web--pkg_x--en` | бот показывает /paid-start на английском |

## Не сделано

- Видео и картинки с русскими надписями (`reels.mp4`, `carousel.mp4`, примеры
  `*_primer.*`) — на английских страницах пока русские. Для LV есть свои (`*-lv.mp4`).
- `hreflang` и карта сайта для поисковиков.
- Штатные письма и сообщения бота на английском — в английском флоу бота они уже есть.
